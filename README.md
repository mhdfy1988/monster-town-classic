# 青芽纪行 · Pocket Grove

可在浏览器游玩的中文俯视像素怪兽 RPG。当前第一章已可完整通关：从青芽镇领取伙伴，完成捕捉与巡林员资格挑战，接受博士的森林调查委托，穿过风铃森林，在回声洞穴解除三段声锁并安抚熔岩巨龟，最后返镇完成调查结算。

项目路径：`D:\learn_code\monster-town-classic`

## 技术体系

- TypeScript + Vite
- Phaser 3.90.0
- 自适应可用空间的游戏画布（Phaser RESIZE）
- 32×32 地图格
- 最近邻采样和格子移动
- 游戏内部按内容、领域、系统、世界、战斗和界面分层，详见 [工程架构](docs/architecture.md)。

## 当前可玩内容

- 战斗主指令为招式、道具、更换、逃跑；撞击、属性伤害、叫声和守护统一属于招式，不再把“普通攻击”另拆成一类。道具包含捕捉、回血、攻击强化及解除攻击弱化，状态只在本场战斗内生效，商店提供补给。
- 战斗胜利后进入全队成长结算：本场首发获得完整经验，其余随行伙伴获得 60% 同行经验；界面逐位展示经验增长、等级提升、新招式、招式进化与形态进化，再返回探索。
- 图鉴按形态独立展示，实际捕获/进化后解锁并写入现有存档；初阶、中阶、终阶不再共用一个列表条目。当前 8 个种族、24 个形态，按 001—024 独立编号。

- 怪兽重设计已完成火、土、水、木、金、冰、光、雷八条三阶线，共 24 张精细像素正背二视图；均在 10/20 级战斗结束后进化，每阶实际获得后独立解锁图鉴。编号、名称和资源路径见 [怪兽形态目录](docs/creature-form-catalog.md)。

- 首页采用“像素旅行档案”布局：左侧以第一章路线和三只代表伙伴建立冒险封面感，右侧集中开始、继续、存档管理与结束游戏。开始游戏直接进入新旅程，不创建或覆盖存档；首次手动保存才选位置，此后手动和自动保存写入该位置。支持键盘上下选择、Enter 确认、继续最近存档、三个存档位管理和结束游戏，未保存返回标题可保存、放弃或取消。
- 存档仅在当前浏览器本地保存；删除需确认，清除网站数据会丢失进度。网页版结束游戏显示安全关闭提示，不强制关闭标签页。

- 青芽镇、研究所室内、48×36 的独立野外地图风铃森林，以及 44×34 的独立回声洞穴；四张运行地图分别拥有稳定 ID、尺寸、出生点、碰撞、遭遇区和双向出入口。
- 任务日志同时展示由剧情标记推导的九阶段主线，以及独立持久化的支线状态；第一章可完成“迷路的测量员”和“暗淡的苔光”两条支线，奖励只结算一次。
- 三选一初始伙伴；八种属性伙伴可在野外相遇；属性为火、土、水、木、金、冰、光、雷，初始教学闭环为火克木、木克土、土克火。
- 回合制普通/属性攻击、药水、捕捉、换人、逃跑、战败自动救援。
- 五位随身伙伴与收容箱，全队经验成长、免费治疗和补给商人。
- 玩家、小夏、阿澄、林川、旅行商人、青禾博士和青芽镇镇长均使用独立的四方向精细像素行走图；白砾使用已登记的黑金护卫角色资源。
- 结识第二种伙伴后挑战巡林员，获得青芽徽章；返回研究所接受博士正式委托后北门才开放。森林调查包含测量员、苔光线索与白砾首次登场；清理北侧通道后进入回声洞穴，按低音、中音、高音顺序激活回声石，关闭过热设备并迎战不可捕捉、不可逃跑的熔岩巨龟。胜利后必须返镇听取镇长、博士和林川的结算，镇长才签发河湾镇通行证。第二、三章地图仍在规划中。
- 独立本地存档，刷新后可继续旅行。首次键盘或鼠标操作后自动解锁音频；探索／战斗音乐会随场景切换，背景音乐和游戏音效可在设置中分别开关、调节音量并持久化。

游戏入口：`http://127.0.0.1:4190/`。WASD / 方向键移动，E / 空格交谈，T 队伍，B 背包，M 手册。战斗用鼠标选择指令。

捕捉演出默认使用正式像素粒子方案：捕捉球沿平滑弧线落到怪兽右下方，怪兽从靠球侧逐步粒子化，颗粒实时采样当前立绘的透明轮廓与颜色后分批吸入球体。`?captureFx=classic` 仅保留为开发对照入口，移除参数或使用 `?captureFx=pixel` 均进入正式方案。两套表现共用同一捕捉规则，不影响概率、库存和存档。

本版地图仍使用 Tuxemon 开放素材，24 个怪兽形态与主要人物使用项目新制像素资源；沿用 Phaser，无新增运行依赖。素材原生尺寸与显示尺寸分开管理：16×16 地图素材最近邻放大至 32×32 逻辑格；新人物图表为 3×4、单帧 48×64，按原尺寸显示并以脚底中心落在 32×32 逻辑格上。完整来源、许可和实现路径见 [第一章说明](docs/rpg-first-chapter.md)。

游戏由 `src/rpg/gameApp.ts` 启动，`RpgScene.ts` 只承担场景生命周期和用例编排；资源、世界绘制、移动、洞穴机关、任务进度、战斗流程、存档与通用界面已进入对应模块。第一章地图内容位于 `src/rpg/content/maps/`，由运行地图注册表统一提供地图 ID、尺寸、碰撞、出生点、遭遇区和传送点。风铃森林与回声洞穴使用项目内部的静态地图文档，经适配器进入统一运行地图接口。早期地图编辑器、旧 Phaser 原型场景、试验图块代码及其浏览器入口均已移除，不保留静默回退。

后续内容的结构门禁已固定为三章：3 座独立小镇、3 片独立野外、3 处洞穴和 3 个章节首领，由“小镇 → 野外 → 洞穴 → 首领”的剧情顺序连接。镇内长草区只算教学区域，不算正式野外地图。`src/rpg/content/campaign.ts` 记录稳定内容 ID 和实现状态；第一章的青芽镇、风铃森林、回声洞穴与熔岩巨龟已实现，第二、三章地图和首领仍明确标记为规划中。完整剧情见 [三章主线与地图规划](docs/design/三章主线与地图规划.md)。

运行时成品只保存在 `public/assets/`；源素材、历史导出、制作过程和视觉回归证据分别保存在 `assets/source/`、`assets/workbench/` 和 `assets/qa/`，默认不进入提交和构建。完整边界、尺寸契约与入库流程见 [素材库规范](docs/asset-library.md)。

本版不使用 Three.js、真实三维模型或 Tripo。中文剧情、地图编排与游戏规则在本项目实现；开放素材保留原作者署名，不能声称全部美术原创。

## 运行

游戏使用32×32逻辑地块，画布填满顶部与底栏之间的剩余空间。窗口尺寸改变时调整可见范围，保持地块尺寸、碰撞和地图数据不变。

```powershell
npm.cmd install
npm.cmd run dev -- --port 4190
npm.cmd test
npm.cmd run check:assets
npm.cmd run build
npm.cmd run deploy
```

打开 `http://127.0.0.1:4190/`，使用方向键或 WASD 移动。

`npm.cmd run dev` 与 `npm.cmd run build` 会在缺失时从作者官方 v3.2.0 Release 下载 Zpix 字体；字体二进制不进入源码仓库。项目使用相对 Vite `base`，可部署到 GitHub Pages 项目子路径。

`npm.cmd run deploy` 会先重新执行测试、资源门禁与生产构建，再更新专用 `gh-pages` 发布分支；它不会把 `dist` 提交到 `main`。
