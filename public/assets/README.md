# 运行资源库

此目录只保存浏览器游戏实际加载的成品资源，会被 Vite 原样复制到构建产物。目录用途：

- `characters-v2/`：当前游戏 48×64 单帧、3×4 四方向人物图集。
- `creatures-v2/forms/`：001—024 怪兽正背双视图成品。
- `environment/`：森林与洞窟场景物件图集。
- `fonts/`：界面字体及来源说明。
- `items-v2/`：捕捉球和药剂成品图。
- `tuxemon/`：仍在运行时使用的开放素材及完整署名、许可文本。

源参考图、历史备份、生成候选和 QA 截图不得放入本目录。新增运行资源后执行 `npm.cmd run check:assets`，并在实际界面按最近邻采样和目标显示尺寸验收。
