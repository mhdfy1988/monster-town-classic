# 沉浸式游戏界面阶段

## 标题与存档（2026-09-14）

- `title.css` 提供全屏森林标题、纵向选项、键盘焦点和窄屏布局；开始游戏直接创建内存中的新旅程，不选择或覆盖存档。首次手动保存才选位置，此前自动保存不落盘；后续保存写入已选位置。继续游戏读取最近保存的有效存档。网页版结束停留在关闭提示页。
- 未保存返回标题提示保存、放弃或取消；保存并返回时先选择存档位，取消选位不会丢失内存进度，只有成功写入才返回标题。此规则取代此前“开始时选择位置”的设计。
- `saveSlots.ts` 复用 `validSave` 校验领域数据，三个位独立保存到 `pocket-grove-slots-v1`。首次读取才迁移旧 `pocket-grove-rpg-v1` 到一号位，保留旧键但不再写入；新目录损坏时显式报错，绝不回退旧档。删除后空位不会从旧档重新出现。
- 首次保存选择已有位置时需确认覆盖，删除也需确认；选定位置成为当前手动及自动保存目标。当前槽删除后不自动重建，需要重新选择保存位置。浏览器清理数据仍会丢失进度，当前没有云存档。
- 键盘证据：Phaser `src/input/keyboard/KeyboardPlugin.js` 的 `addKeys` 默认启用捕获；`KeyboardManager.js` 对捕获按键调用 `preventDefault`，使 DOM 按钮的原生 Enter 激活失效。弹窗层显式激活聚焦按钮并阻止事件流入场景；测试必须包含真实按键，不能只用 click。
- 验证：35 项单元测试，`scripts/check-title.cjs` 后台独立上下文覆盖新建、键盘选择确认、续玩、存档隔离、删除取消/确认、刷新和结束；旧档迁移/损坏保护由单元测试覆盖。未操作用户浏览器存档。

## 收藏与道具可视化（2026-09-14）

- `collections.css` 为背包、商品、图鉴和队伍统一视觉层；复用 `portraitUi.ts` 的道具矢量图标与已有正面像素图集，不添加虚构物品或新存档字段。
- 背包选中道具查看用途、数量及首发伙伴，用药后立即刷新；商店展示商品大图并保留库存与金币校验；图鉴以捕捉记录解锁图片、名称和招式，未知项只显示剪影；收容箱点击卡片继续使用原加入/交换规则。
- `check-dialogs.cjs` 覆盖桌面和 390×844 下四处面板横向边界、药水消耗和恢复量、购买扣款和库存变化，全部在无头临时浏览器执行。31 项单元测试通过，已查看桌面实际截图。窄屏允许面板内部纵向滚动。
- 战斗背面素材问题仍是独立待处理项，本轮没有替换战斗素材。

## 弹窗与按钮美化（2026-09-14）

- `immersive.css` 统一暖色纸面、深绿标题牌、金色双层描边和底部投影；主操作为绿色，普通操作为浅色，补齐悬停、按下、焦点和禁用反馈。减少动态效果偏好下关闭入场动画。
- 作用域限定在弹窗和设置面板，不改变战斗分区、地图尺寸或场景独立快捷图标。通用弹窗移除重复的旅行手册副标题。
- 构建与 31 项测试通过；后台无头检查背包、商店、队伍、对话框边界以及 390×844 商店横向溢出，通过后查看实际截图。队伍长内容保留面板内滚动，本轮不等同于完整玩法回归。
- 验证脚本：`scripts/check-dialogs.cjs`；Playwright 已作为开发依赖声明，首次运行需安装 Chromium。截图位于 `assets/qa/dialogs/`。测试不接管用户浏览器、不修改用户存档。

## 战斗布局修复（2026-09-14）

- 原百分比站位、固定精灵尺寸与独立血条定位，在 390px 宽度下使敌方精灵越出右边界；800×450 下我方血条盖住敌方精灵。
- `battle.css` 将战场分成两列两行，状态框和精灵各有独立区域；使用容器宽高共同约束精灵显示尺寸，同步背面图集偏移，取消旧 transform 缩放。指令区独立占位。
- 六个指令加入彩色图标，属性招式按当前怪兽对应草、火、岩、灵图标，不添加不存在的技能。
- 静态检查 1280×720、800×450、960×540、390×844、360×640：精灵不越界、不与血条重叠，六个指令全部可见。已人工检查实际战斗截图。
- 390×640 攻击和反击过程采样 260 次，精灵均在战场内，回合结束解除 busy；31 项测试通过，构建通过。独立测试，不覆盖用户窗口尺寸或存档。
- 验收规则：不仅检查指令可见性，还要同时检查双方精灵矩形、状态框重叠和动画期间边界。

## 当前入口修订（2026-09-14）

按用户纠正，背包、图鉴、队伍、设置不再藏在旅行菜单里。四个独立彩色道具图标常驻画面右下角，没有矩形按钮底板，悬停/键盘聚焦才显示名称。点击直接进入对应功能；设置保留声音、记录旅程和工坊入口。对话/战斗期间隐藏整组图标，防止越过模态状态。下文菜单内图标的描述是前一轮实现记录，以本条为准。

复用原事件入口与快捷键；独立 ui-check=dock 测试四个入口均可打开，已检查场景截图。构建和 31 项测试通过。未改用户存档或浏览器尺寸。

## 目标与实现

将“网页容器内的游戏”改为“打开就是游戏”。保留 Phaser、现有地图、战斗与存档协议，仅调整界面组织。

- `src/main.ts`：场景铺满窗口；地名短暂展示；右上角菜单入口；伙伴、背包、图鉴、保存、设置和工坊入口收进旅行菜单。
- `src/rpg/RpgScene.ts`：复用原有伙伴、背包、手册、保存调用；菜单打开进入模态状态暂停移动；Esc 关闭，T/B/M 切换功能。战斗中不允许打开旅行菜单。普通对话显示在底部。
- `src/rpg/immersive.css`：统一米白色像素边框、深绿描边和轻投影，移除网页页头、页脚、地图外框。保留原面板的内容功能，不新增素材依赖。

状态：探索 → 打开菜单（停止移动）→ 选择功能面板 → 关闭 → 返回探索；战斗指令仍由原战斗状态控制。浏览器尺寸变化只改变可见地图范围，不把人物与地块拉伸。
