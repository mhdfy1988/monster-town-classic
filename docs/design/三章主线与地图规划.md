# 《青芽纪行》三章主线与地图规划

## 设计定位

这是当前三章主线的第一版权威设计。故事保持轻冒险基调，不做救世史诗：玩家从一次镇外调查开始，逐步发现一项原本想改善交通的工程正在伤害伙伴栖息地，最后帮助工程负责人换一种与伙伴合作的办法。

当前可玩内容已经贯通第一章：青芽镇、领取伙伴、镇内遭遇教学、巡林员挑战、独立风铃森林、独立回声洞穴、三段声锁、过热设备和熔岩巨龟首领战。镇内长草区不是风铃森林，巡林员挑战也不是第一章最终首领。第二、三章仍是设计与内容契约，尚未制作运行地图。

## 世界冲突

三座小镇之间的旧山路危险、运输缓慢。研究员紫棠提出“引路塔计划”：在野外抽取八种属性能量，为道路、桥梁和夜间路标持续供能。她的目标不是破坏环境，而是让各地重新连通。

问题在于设备抽取速度过快。森林升温、河道倒灌、雷暴加剧，原本温和的高阶伙伴开始守护能源节点。工程护卫白砾认为停机只会让三镇再次隔绝，紫棠则相信只要完成中央塔就能一次解决所有问题。玩家需要找到三台设备、安抚三只首领伙伴，并证明“由伙伴主动供能”比强行抽取更稳定。

## 固定地图拓扑

每个名称都代表独立地图资源，不是同一张大地图里的区域标签。

```text
第一章：青芽镇 → 风铃森林 → 回声洞穴 → 熔岩巨龟
                       ↓
第二章：河湾镇 → 芦苇湿地 → 沉水洞窟 → 巨浪水龙
                       ↓
第三章：雷石镇 → 雷鸣高原 → 废弃矿洞 → 雷牙虎 → 中央引路塔结局
```

章节之间通过道路出口和剧情通行证连接；进入下一章后仍可返回旧地图。城镇负责补给、NPC 和剧情选择，野外负责探索、捕捉和路线分支，洞穴负责机关、资源管理和首领前压力。

## 第一章：森林发热了

### 开篇

玩家来到青芽镇，在青禾博士处领取第一位伙伴。完成镇内遭遇教学并击败林川后获得青芽徽章。林川说明这不是冠军徽章，只代表具备接受镇外调查的资格；玩家必须回研究所接受青禾博士的正式委托，北门才会开放。

### 风铃森林

- 独立野外地图，主题是木、火、光属性伙伴。
- 主路被倒下的树阻断，玩家需要从两条支路寻找受惊伙伴和失踪的测量员。
- “迷路的测量员”支线要求找到森林中的测量员并向林川报平安；“暗淡的苔光”支线要求调查三处生态线索并向小夏提交记录。
- 森林深处出现不正常热风，夜间发光苔藓也在减少；两条支线共同证明异常并非普通季节变化。
- 白砾要求玩家离开施工区域，第一次说明引路塔工程的道路供能目的，也让玩家知道洞穴设备并非天然遗迹。

### 回声洞穴

- 独立洞穴地图，主题是土、火属性伙伴。
- 洞口明确说明这里是旧引路塔设备的试验场，当前声锁和矿轨都是工程设施，而不是紫棠刚留下的现场标记。
- 当前核心机制是环形矿车轨道和声响引路：玩家必须依次确认低音、中音、高音回声石；错误音序会重置路标。推石作为后续丰富洞穴交互的候选，不属于当前已验证版本。
- 玩家关闭过热的第一台抽取设备，但被热量惊醒的熔岩巨龟挡住出口。

### 首领与结尾

首领为熔岩巨龟。胜利不是捕捉它，而是打掉失控状态并让设备彻底停机。首领战只记录“熔岩巨龟已平静”，不会在洞穴里直接完成章节。玩家返镇后依次听取林川、博士的调查结论，最后由镇长确认森林问题来自工程设备并签发河湾镇通行证；同类设备仍有两台的线索由旧试验场资料和白砾对白共同承担。

## 第二章：河水走错了方向

### 河湾镇

- 独立城镇地图，以桥梁、码头、磨坊和水路运输为核心。
- 镇民一部分支持引路塔，因为设备曾恢复夜航；另一部分反对继续抽水。
- 玩家需要先修复两处水闸，才能进入湿地深处。

### 芦苇湿地

- 独立野外地图，主题是水、冰、金属性伙伴。
- 水位随开关变化，浅滩、木桥和乘筏路线构成多层探索。
- 炮甲兽破坏旧水闸并非主动袭击，而是在阻止设备继续抽水。
- 玩家找到紫棠的记录：第一台停机后，中央塔开始从第二台设备加倍抽取。

### 沉水洞窟

- 独立半淹没洞穴地图。
- 核心机制是升降水位：低水位可走地面，高水位可乘浮台抵达高处。
- 白砾与玩家发生一次训练家战斗，失败后仍坚持中央塔必须完成，但允许玩家进入核心区验证判断。

### 首领与结尾

首领为巨浪水龙。玩家先恢复洞窟水流，再安抚守在泉眼的首领。紫棠首次亲自出现，承认抽取方案有问题，但第三台设备已经自动启动；如果直接关闭，中央塔积存的能量会在雷石镇上空失控。

## 第三章：雷暴下的选择

### 雷石镇

- 独立城镇地图，建在矿山和高原入口之间。
- 长时间雷暴导致升降机停运、矿工被困，居民希望玩家先救人而不是追查设备。
- 玩家修复镇内避雷装置，获得进入高原的许可。

### 雷鸣高原

- 独立野外地图，主题是雷、光并混合前两章属性伙伴。
- 雷击会周期性改变可通行路线；玩家利用避雷柱建立安全区。
- 小夏、林川和两镇支援人员在不同路线协助撤离受困者，让此前结识的角色真正参与终章。

### 废弃矿洞

- 独立洞穴地图，也是中央引路塔的地下供能通道。
- 核心机制是恢复矿车线路、切换导电轨道和关闭三组过载开关。
- 白砾最终选择帮助玩家疏散工人；紫棠留在中央控制室尝试阻止爆发。

### 首领与结局

首领为雷牙虎。它不是被设备控制，而是在主动咬断输能线路。玩家战胜并理解它后，与自己的队伍共同把中央塔从“强行抽取”切换为“伙伴主动共鸣”。三镇道路重新亮起，但只在有伙伴愿意协助时运行。

结局回到青芽镇。紫棠承担修复责任，白砾负责三镇道路巡查，青禾博士建立伙伴观察站。玩家获得三镇联合旅行证，主线结束后可继续捕捉、挑战和完成支线。

## 关卡节奏不变式

1. 每章必须依次经历城镇目标、独立野外探索、独立洞穴探索和章节首领。
2. 每张野外至少包含一条主路、两条可选支路、一个回环捷径和一个返回城镇的出口。
3. 每处洞穴必须有自己的探索机制，不能只是换成深色贴图的线性走廊。
4. 首领胜利必须解决本章环境问题，并改变下一章的进入条件。
5. 旧地图保持可返回；剧情门只控制出口或事件，不删除玩家已经获得的伙伴和资源。
6. 当前八条伙伴进化线优先承担生态和首领角色，不为填地图立即扩充大量新怪物。
