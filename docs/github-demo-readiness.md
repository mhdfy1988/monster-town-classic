## 建议的发布顺序

1. 提交前执行测试、资源门禁和生产构建，确认没有源参考、日志、`dist`、`node_modules`、本地缓存或 QA 证据进入 Git。
2. 推送 `main` 后执行 `npm.cmd run deploy`；命令会下载缺失的官方字体、重新执行门禁，并仅把 `dist` 发布到 `gh-pages` 分支。
3. 部署成功后访问真实 Pages URL，检查标题、移动、战斗、背包、图鉴、字体、图片和音频；HTTP 200 不能代替真实页面回归。

首页发布回归至少覆盖 1280×800 桌面、390×844 竖屏和 800×450 矮屏；`scripts/check-title.cjs` 会检查主菜单存档语义、键盘导航、伙伴可见性和结束游戏入口边界。针对临时或线上地址运行时，通过 `RPG_ORIGIN` 指定目标，不需要修改脚本内的固定地址。

GitHub Pages 适合发布静态 Demo；当前游戏存档只保存在访问者浏览器本地，不会随 Pages 自动同步。字体许可应以 [Zpix 作者仓库](https://github.com/SolidZORO/zpix-pixel-font) 的最新原文及必要的授权确认作准。Tuxemon 素材按项目内署名表逐项核对，不能笼统称为全部原创。
