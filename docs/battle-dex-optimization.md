# 战斗界面与独立形态图鉴优化

## 范围与验收

本阶段合并用户指定的两项目标：圆润、图标化的游戏界面，以及进化形态独立图鉴。当时未批量制作其余 19 条进化链；后续阶段已经补齐为 8 个种族、24 个形态。

- 主入口始终为 `http://127.0.0.1:4190/`，测试只启动独立无头浏览器，不清理用户存档、不修改用户标签页。
- 当前实现：5 个种族、7 个形态。每个形态通过稳定键 `种族ID:形态` 保存解锁记录，中文名称和列表位置不作为存档键。
- 捕获/领取解锁实际形态，战斗结束发生进化时追加新形态。预览未知条目只显示剪影，不增加计数。
- 旧档没有 `dexForms` 时，只推断已捕获初阶和当前队伍/收容箱已有形态；不按等级推断未发生的进化。旧档无法还原已经失去且从未记录的历史形态，不捏造解锁。

## 战斗交互

主菜单为攻击、技能、道具、更换、逃跑。技能/道具子菜单保持战场可见，返回不消耗回合。成功执行指令后敌方行动；无库存、满血治疗、无弱化可解除等无效道具不消耗库存或回合。

- 属性攻击使用当前形态招式；威吓降低对手攻击，每层 20%，最低 -2 层。
- 守护减少下一次实际受击伤害 50%；敌方只使用威吓时不消耗守护。
- 力量药剂提高攻击一层，上限 +2；净化药剂清除攻击弱化。首版没有中毒、睡眠等其他异常，不把这些状态写成已实现。
- 战斗状态保留在本场伙伴对象上，更换不会清掉该伙伴状态，下一场统一清空；不写入探索存档。
- 新游戏提供力量/净化各 2 份，旧档缺失库存按 0 显示，可到商店购买。库存仍由现有 `Save` 持久化。

## 接地与视觉依据

旧定位依据图片框中心，不能代表脚底。火系母版含透明边距与长尾，旧图集也有不同帧边距。现在原图不改，SVG 独立视窗裁出该帧，明确脚底基线；立绘底部与阴影中心共用同一个单元内位置。

`portraitUi.ts` 记录实际透明范围。原 Tuxemon 图集为 128×88，上方是两个 64×64 战斗帧，下方不是战斗身体，不可整张拉伸。规则适用于接地，不意味着旧怪兽已全部重画。

`game-ui.css` 是本阶段游戏皮肤，圆润框、属性徽章、图标指令、无独立矩形底色的标题统一在这里维护。

## 验证入口

- 用户追加反馈已纳入：增益/减益改为剑与箭头、守护盾牌图标，角标表示层数，鼠标悬停/键盘聚焦/点按可查看说明。背包、图鉴和空队伍提示不再使用底部整行“返回旅行”，改为右上角关闭图标，保留 Esc。

- `npm.cmd run build` / `npm.cmd test -- --run`：构建与 45 项测试。
- `scripts/check-optimization.cjs`：五指令与子菜单、实际状态效果、捕捉、实际胜利进化、未知形态不解锁、存档刷新、药剂购买、1280×800 / 390×844 / 844×390 视口、原有怪兽截图。
- `scripts/check-evolution.cjs`：三阶战斗、进化、存档及队伍回归。
- 截图输出 `assets/qa/optimization/`。脚本不连接或重置用户浏览器。
