# 怪兽形态编号表

本表是 24 个怪兽形态的资源与展示名称权威清单。编号属于具体形态，不等同于运行时种族数组下标。

## 编号规则

- 001—008：初始形态，依次为火、土、水、木、金、冰、光、雷。
- 009—016：进阶形态，属性顺序不变。
- 017—024：最终形态，属性顺序不变。
- 正面与背面二视图使用同一张透明 PNG；每个视图必须单独保存内容边界与脚底水平锚点。
- 运行时资源路径统一为 `/assets/creatures-v2/forms/<编号>.png`。
